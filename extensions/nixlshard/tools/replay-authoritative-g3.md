```sh
python3 /workspace/replay-authoritative-g3.py \
  --mode remote \
  --base-harness /workspace/bench-ttft.py \
  --replay-helper /workspace/bench-ttft-replay.py \
  --reference-artifact-dir /scratch/nixlshard-v2/authoritative-g3/20261005-a10-b7-remote-staged/requester/remote-full \
```

For traffic, remove `--validate-only`, add `--expected-plan-sha256` with the accepted fingerprint above, and append the unchanged complete benchmark CLI after `--`. Staged and direct remote runs use the same wrapper and reference. Only the direct candidate adds the existing benchmark `--direct-receive` flag.

For each local context epoch, substitute this wrapper for the benchmark subprocess command, use `--mode local`, point the reference at the original local requester role directory, and append the existing epoch CLI with `--contexts CONTEXT --scenarios cold gpu host ssd`. The existing supervisor retains flush/detach/drain/file-descriptor checks/unlink/attach between epochs. The wrapper does not perform administrative operations.

Every candidate reuses its accepted token IDs and deterministic sampling parameters. GPU hits immediately reuse the preceding cold request. Host and local SSD hits reuse their own accepted seed request. Host-pressure preparation prompts remain randomly generated by the frozen benchmark and are excluded from measured TTFT; this limitation remains explicit. Per-sample output comparison against the accepted baseline is outside the measured stream window. A local mismatch marks the saved sample failed and produces a separate verification record.

Run this long experiment in the existing bounded background supervisor; retain exit status, raw data, wrapper SHA, complete/selected plan fingerprints and original source pins. Keep source and reproduction scripts in Git or RAID. GCS may contain approved request/data JSON, logs and SHA manifests, never wrapper source or credential values. The source files are separate from the frozen runtime/native marker.

The companion regression tests use saved baseline artifacts only and make no serving requests. They cover complete archived plans, cold/GPU mismatches, sample order/fingerprints, missing cases, seed sampling changes, immutable source/plan gates, relocation and actual replay-hook order/output handling.

Set `G3_REPLAY_LOCAL_REFERENCE` and `G3_REPLAY_REMOTE_REFERENCE` to the restored baseline directories before running the tests. The driver/base source defaults are sibling files; `G3_REPLAY_BASE_HARNESS` and `G3_REPLAY_HELPER` may override the frozen source locations. Without the archived fixtures, tests skip with an explicit message. `NIXLSHARD_TEST_DIR` can select the temporary-file directory, such as `/raid/nixlshard-v2` on the development host.

For example, with the restored accepted fixture directories on the development container:

```sh
export G3_REPLAY_LOCAL_REFERENCE=/workspace/replay-reference/local
export G3_REPLAY_REMOTE_REFERENCE=/workspace/replay-reference/remote/remote-full
export G3_REPLAY_BASE_HARNESS=/workspace/src/nixl/extensions/nixlshard/tools/bench-ttft.py
export G3_REPLAY_HELPER=/workspace/src/nixl/extensions/nixlshard/tools/bench-ttft-replay.py
```
